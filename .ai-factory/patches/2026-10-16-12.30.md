# CI checks must exercise the current contracts

## Failure

The architecture branch failed the repository quality jobs, offline sidecar
lint, browser campaign flow, and CodeQL checks after publication.

## Cause

- The EditorConfig setup action expected obsolete release asset names; setup
  also had no explicit checker invocation.
- Markdown examples had invalid fence/list structure, while Makefile recipes
  legitimately require tabs. Syntax-aware formatters are responsible for
  numerical continuation indentation, including embedded SQL strings.
- Ruff rejected unused suppressions and two redundant expressions.
- The campaign browser mock used a different hostname from the API client.
- CDP interpolation needed explicit escaping at the JavaScript boundary;
  nonce tests used fixed values that resembled credentials to static analysis.
- Frontend coverage reporters did not produce the files consumed by CI.

## Prevention

Run the actual checker after installing a pinned tool. Keep format exceptions
narrow, preserve literal examples, and reproduce browser routes against the
production build. Serialize CDP arguments through the shared escaping helper
with round-trip regression cases. Generate runtime-only test nonces and retain
the replay and invalid-length assertions. Check the expected coverage artifacts
in addition to the test exit code.
