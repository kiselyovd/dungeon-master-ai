# CI checks must exercise the current contracts

## Failure

The product branch failed quality checks, offline sidecar lint, a frontend
invitation assertion, browser flows, and CodeQL after publication.

## Cause

- EditorConfig setup expected obsolete release asset names and did not invoke
  the checker. Numerical indentation checks also treated valid SQL strings
  and Markdown continuations as source indentation.
- Markdown examples and spelling fixtures failed the actual repository globs.
- Ruff rejected unused suppressions and two redundant expressions.
- Browser tests still expected earlier dialog and character creation flows.
- An invitation test read the DOM before the asynchronous refresh completed.
- CodeQL propagated secret taint through a mixed public/private room grant,
  identified fixed test nonces and assertion messages, and required explicit
  escaping at the CDP JavaScript interpolation boundary.
- Frontend coverage reporters did not produce the files consumed by CI.

## Prevention

Invoke installed checkers explicitly and keep format exceptions narrow.
Exercise current production UI paths without reducing behavior assertions.
Wait for observable asynchronous state transitions. Obtain public room IDs
through the existing public repository projection for transport tests; keep
capability and replay checks intact. Use static redacted assertion messages,
runtime-only test nonces, and a shared CDP literal serializer with regression
cases. Check expected coverage artifacts as well as test results.
