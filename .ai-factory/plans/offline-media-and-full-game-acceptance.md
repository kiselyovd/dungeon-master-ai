# Offline Media and Full-Game Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task in the current branch. Multi-agent execution is disabled for this session. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make maps and illustrations work without Stable Diffusion through an honest bundled fallback, eliminate false-positive real-Tauri play checks, and prove the complete game loop through deterministic and live acceptance.

**Architecture:** `app-application` owns media provenance, `adapter-media` owns bundled and resilient image providers, backend composition always supplies the bundled provider when images are enabled but no primary is available, and the existing typed SSE path carries provenance to the React projection. Deterministic Playwright proves mechanics; a separate CDP driver proves the real Tauri/WebView2, local model, SDXL, and fallback paths without conflating them.

**Tech Stack:** Rust 2021, Axum SSE, React 19, TypeScript 6, Zustand, Valibot, Vitest, Playwright, Tauri 2/WebView2 CDP, Bun, and existing image-generation tooling.
